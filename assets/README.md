Put the company logo here as `logo.png`: square, at least 1024×1024, transparent background (the original is
`C:\Users\CHANTCH\Projects\chantch-storefront\ref\logo.png`). `apply.py` derives every icon from it: Windows `.ico`
files, the macOS `.icns` and app-icon PNGs, the tray icons (the macOS tray uses a single-colour silhouette of the
logo's shape) and the in-app logo. Optional `tray-mac.png`: the shape to use for the macOS menu-bar icon instead of
`logo.png` (needed when `logo.png` sits on a plate, whose silhouette would be a plain square); its silhouette is used.
